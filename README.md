# 三国塔防 · Tower of Three Kingdoms

> 一款以三国乱世为背景的网页塔防游戏。玩家选择喜爱的武将，排兵布阵、建造并升级防御塔，抵御一波波敌军，跨越 **50 关**史诗战役，最终决战魔化董卓。

在线体验：`https://play.maozirui.com/webgame/play-tower-sanguo/`

---

## 一、游戏概览

| 项目 | 说明 |
|------|------|
| 类型 | 塔防（Tower Defense）+ 武将技能 |
| 平台 | 浏览器（HTML5 + JavaScript，免安装） |
| 关卡 | **50 关**，5 大战役章节 |
| 核心循环 | 选将 → 布防建塔 → 迎击敌潮 → 放技能 → 升级强化 → 通关 |
| 胜利条件 | 守住基地（血量 > 0）撑过本关全部波次 |
| 失败条件 | 基地血量被敌军耗尽 |

---

## 二、技术架构（极致视觉方案）

| 层级 | 技术 | 说明 |
|------|------|------|
| 渲染 | **Three.js** | 3D 动态背景 + 2D 正交角色/塔/特效，粒子技能 |
| 物理打击 | **Planck.js 思路 / 自研轻量物理** | 投射物轨迹、击退、屏幕震动，强化打击节奏感 |
| 动画 | **Sprite 序列帧**（参考 Spine 骨骼动画） | 主角/小怪/Boss 行走、攻击、施法、死亡 |
| 关卡 | **自定义关卡解析器** | 数据驱动，50 关路径/波次/地形可配置 |
| 音频 | **Web Audio API** | BGM + 战斗/技能音效，节拍同步 |
| AI 素材 | MiniMax image-01 / music-2.6 | 背景、角色、特效、BGM 全部 AI 生成 |

## 三、可选武将（专属技能）

每位武将都有独特定位与**主动大招**（冷却释放）+ **被动光环**。

| 武将 | 定位 | 主动技能 | 被动 |
|------|------|----------|------|
| **赵云 · 龙胆** | 均衡/突进 | **七进七出**：化作银龙贯穿全屏路径，对直线上敌人造成巨额伤害并击退 | 全军攻速 +10% |
| **关羽 · 武圣** | 爆发/AOE | **青龙偃月**：召唤青龙刀气横扫半场，大范围斩击并眩晕 | 攻击塔伤害 +15% |
| **诸葛亮 · 卧龙** | 控制/谋略 | **东风火计**：呼东风唤天火，持续灼烧区域内敌人并减速 | 技能冷却 -20% |
| **吕布 · 无双** | 极致单体 | **天下无双**：方天画戟落地一击，对最密集敌群造成毁灭性伤害+大范围震屏 | 暴击率 +25% |

技能特效均由 AI 生成（风暴 / 火焰凤凰 / 雷电巨龙 / 青龙刀气），配合粒子与屏幕震动，打击感十足。

## 四、防御塔（可建造 · 点击升级，共 3 级）

| 塔 | 攻击方式 | 特点 | 升级强化 |
|----|----------|------|----------|
| **连弩塔** | 快速单体箭矢 | 攻速快、射程远 | 伤害↑ 攻速↑ |
| **符法塔** | 法术弹，小范围溅射 | 克制成群敌人 | 溅射范围↑ |
| **火炮塔** | 范围爆炸 | 高 AOE、对重甲有效 | 爆炸半径↑ |
| **寒冰塔** | 减速冰晶 | 控制、为其他塔争取输出时间 | 减速效果↑ |

- 点击空地 → 弹出建造轮盘选塔。
- 点击已建塔 → 弹出**升级 / 出售**面板。
- 击杀敌人获得金币，用于建造与升级。

## 六、50 关战役设计

5 大章节，每章 10 关，难度曲线递增，地形与背景各异。

### 第 1 章 · 中原逐鹿（1–10 关）平原
教学与上手。敌人以步兵为主，逐步引入骑兵与盾兵，第 10 关迎战 **华雄**。

### 第 2 章 · 竹林伏兵（11–20 关）密林
路径多弯、刺客登场，考验减速与爆发配合。

### 第 3 章 · 赤壁水战（21–30 关）江河
水路长直道，火炮塔大放异价，第 30 关决战 **魔化董卓**。

### 第 4 章 · 北境雪原（31–40 关）雪原
高速骑兵海 + 高护甲盾兵混合，强调塔的组合与升级节奏。

### 第 5 章 · 魔域决战（41–50 关）火山/魔域
全敌种混合 + 精英怪，第 50 关迎战 **魔帝**，全屏 Boss 技能。

> 每关数据（出怪路径、波次构成、数量、血量、速度、奖励金币）均在 `js/levels.js` 中数据驱动，可调可扩展。

## 七、素材来源

| 内容 | 来源 |
|------|------|
| 背景 / 角色 / 塔 / Boss / 特效 | MiniMax **image-01** AI 生成 |
| 背景纯音乐（菜单/战斗/Boss） | MiniMax **music-2.6** AI 生成 |
| 战斗 / 技能 / 爆炸音效 | 本地古风音效库精选 |

角色动作采用 **Sprite 序列帧**（参考三国志 Spine 骨骼动画的节奏与姿态）实现行走、攻击、施法、受击、死亡。
