# 三国烽火 · 三国塔防 50 关

> 摆武将当塔，扛住一波波敌兵，50 关守到三国一统。
> 三国题材 2D 塔防（H5 网页版）。

在线体验：`https://play.maozirui.com/webgame/play-tower-sanguo/`

## 一、核心定位

| 项 | 决策 |
|----|------|
| 类型 | 三国题材 2D 塔防（双人合作，**当前版本先做单机，双人后补**） |
| 平台 | Web（H5） |
| 玩家 | 1 人（**后续扩展 1~2 人本地同屏**） |
| 单关时长 | 3~8 分钟 |
| 全流程 | 50 关 / 5 章，约 4~6 小时 |
| 一句话 | 摆武将当塔，扛住一波波敌兵，50 关守到三国一统 |

> ⚠️ **当前版本范围**：单人塔防。双人合作、商业化、DLC 均为**后续优化项**，引擎已为其预留接口。

## 四、兵种系统（敌兵 12 种）

**基础 5 种（第 1 章）**：黄巾兵（潮量）、盾兵（高血低速）、弓兵（远程薄血）、骑兵（高速低血）、冲车（慢速高血）

**进阶 4 种（第 2-3 章）**：投石车（远程溅射）、精英武将（BOSS 级单体）、刺客（隐身直奔城内）、治疗兵（回血友军，须先杀）

**终极 3 种（第 4-5 章）**：火船（路径点火烧地）、战象（极高血减速）、妖术师（召唤小怪+治疗）

---

## 五、升级系统（核心爽点）⭐

### 1. 关卡内升级（战斗中）
- 杀怪掉金币，用于放新塔 / 升级现有塔（1★→2★→3★）/ 买技能道具（加速 / 缓速 / 雷击）。

### 2. 关卡间科技树（永久强化）
- 每通关 1 关获得科技点，3 选 1 永久生效。
- **进攻类**：攻速 / 单体伤害 / 穿透 / 暴击 / 技能冷却。
- **防御类**：城防血量 / 城防回复 / 塔血量 / 受击回复 / 复活币。
- **经济类**：杀怪金币 / 起始金币 / 利息 / 关卡奖励 / 拾取范围。

### 3. 武将升级（1★→3★）
- 每章送「将魂」，同类将魂喂武将升星。

## 十、技术方案

| 项 | 方案 |
|----|------|
| 引擎 | Three.js（正交 2D 渲染 + 3D 背景） |
| 语言 | 原生 JavaScript（模块化） |
| 物理/打击 | 自研轻量物理：投射物、击退、屏震、粒子 |
| 路径 | waypoint 序列寻路 + 状态机（寻路→攻击→死亡） |
| 50 关 | 数据驱动 JSON（js/levels.js，手写可调） |
| 美术 | MiniMax image-01 AI 生成 + canvas 去底 |
| 音乐 | MiniMax music-2.6 战斗纯音乐 + 古风音效库 |
| 性能 | 60fps 同屏 100+ 怪（对象池 + 批量渲染） |
