# 三国烽火 · 三国塔防 50 关

> 击杀怪物赚积分，用积分召唤三国名将上阵当塔，固定槽位、可升 3 星，50 关守到三国一统。
> 三国题材 2D 塔防（H5 网页版）。

在线体验：`https://play.maozirui.com/webgame/play-tower-sanguo/`

---

## 一、核心定位

| 项 | 决策 |
|----|------|
| 类型 | 三国题材 2D 塔防（单人，**双人后补**） |
| 平台 | Web（H5） |
| 玩家 | 1 人 |
| 单关时长 | 3~8 分钟 |
| 全流程 | 50 关 / 5 章，约 4~6 小时 |
| 核心循环 | **杀怪得积分 → 用积分召唤武将当塔 → 用积分升星 → 守住 50 关** |

> ⚠️ **当前版本范围**：单人塔防。双人合作、商业化、DLC 均为**后续优化项**。

---

## 二、积分经济（核心）⭐

- **积分是唯一货币**：击杀怪物得积分，用于**召唤武将**和**升星**。
- **积分公式**：`击杀积分 = 怪物分值 × 关卡难度系数 × 科技加成`。
  - 每种怪物有固定分值（黄巾 8 / 盾兵 18 / 精英 50 / 战象 60 / Boss 数百~数千）。
  - 关卡难度系数随章节提升：第 1-5 章 = 1.0 / 1.2 / 1.5 / 2.0 / 3.0。
  - 越往后关卡，同一种怪给的积分越多。
- **科技树**额外加成：杀怪积分 +20%、起始积分 +100、每波利息 +5 等。

## 三·五、势力羁绊系统 ⭐

不同势力武将同场作战会触发**羁绊**——有增益、有中和、也有内耗削弱。同一武将重复上阵只计 1 人。

**① 阵营羁绊（同势力上阵人数，魏/蜀/吴/群 各自独立）**

| 人数 | 名称 | 效果 |
|------|------|------|
| 2 人 | 双璧小成 | 伤害 +10% |
| 3 人 | 三杰大成 | 伤害 +18%、攻速 +8% |
| 4 人 | 四雄鼎盛 | 伤害 +30%、攻速 +12% |

**② 增益组合**：桃园结义（关+张 伤害+12%）、五虎上将（关张赵 伤害+18%攻速+10%）、卧龙凤雏（诸葛+庞统 溅射+25%）、西凉铁骑（赵+马 攻速+15%）、神射连营（黄+马 射程+15%）、忠勇死士（典韦+周泰）、龙争虎斗（司马+诸葛）、美人计（吕布+貂蝉 暴击+15%）。

**③ 内耗组合（同场削弱）**：三英战吕布（吕布遇关羽 伤害-12%）、宿敌相逢（吕布+张飞）、三谋相忌（诸葛+司马+庞统 伤害-15%）、渭水恶战（马超+典韦 攻速-12%）、群英伐吕（吕布遇典韦周泰 伤害-18%）。

**④ 中和组合（无效果）**：英雄美人（赵云+貂蝉）、老将相惜（黄忠+周泰）。

> 战斗 HUD 实时显示当前触发的羁绊数（🤝增益 / ⚠️内耗），图鉴「势力羁绊」页有完整对照表。

## 四、兵种系统（敌兵 12 种 + 5 章 Boss）

**基础 5 种（第 1 章）**：黄巾兵（潮量）、盾兵（高血低速）、弓兵（远程薄血）、骑兵（高速低血）、冲车（慢速高血）

**进阶 4 种（第 2-3 章）**：投石车（远程溅射）、精英武将（BOSS 级单体）、刺客（隐身直奔城内）、治疗兵（回血友军，须先杀）

**终极 3 种（第 4-5 章）**：火船（路径点火烧地）、战象（极高血减速）、妖术师（召唤小怪+治疗）

每种怪物的**血量/速度/护甲/击杀积分/能力**都可在游戏内「📖 图鉴」中查看。

## 五、图鉴说明（📖 按钮）

主菜单 / 选关页 / 战斗页都有「📖 图鉴」按钮，弹窗含两个标签页：

- **怪物图鉴**：12 兵种 + 5 Boss 的头像、血量/速度/护甲、**击杀积分**、特殊能力说明。

## 七、升级系统

1. **关卡内升星**：召唤武将后，用积分升 1★→2★→3★，数值翻倍。
2. **关卡间科技树（永久强化）**：每通关 1 关得科技点，3 选 1 永久生效。
   - **进攻**：攻速 / 单体伤害 / 穿透 / 暴击 / 全军射程。
   - **防御**：城防血量 / 城防回复 / 复活币。
   - **经济**：杀怪积分 / 起始积分 / 每波利息。

## 八、技术方案

| 项 | 方案 |
|----|------|
| 引擎 | Three.js（正交 2D 渲染 + 3D 背景） |
| 语言 | 原生 JavaScript（模块化） |
| 物理/打击 | 自研轻量物理：投射物、击退、屏震、粒子 |
| 路径 | waypoint 序列寻路 + 状态机（寻路→攻击→死亡） |
| 50 关 | 数据驱动（js/levels.js，手写可调） |
| 美术 | MiniMax image-01 AI 生成 + canvas 去底（**WebP 压缩**：精灵 128px、背景 960px，图片总量 19MB→492KB，省 97%） |
| 音乐 | MiniMax music-2.6 战斗纯音乐 + 古风音效库 |
| 性能 | 精灵去底前先缩至 ≤128px 再逐像素处理，加载零卡顿 |
